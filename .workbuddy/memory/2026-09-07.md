## 全书「中道审查」统稿（50 篇）

**任务**：对 `content/` 下全部 50 篇文章做中道视角审查，移除说教感、去除过度夸张表述。

**方法**：先写统一审查准则 `/tmp/zhongdao-review-guide.md`（定义替换规则、红线清单、语气样本），再派 10 个子 agent 按目录分组并行执行。

**踩坑记录（重要）**：
1. **10 个 agent 并发会触发 429 频率限制**。报 429 的分组其实会在后台重试并最终执行成功，`git status` 才是判断依据，不要仅凭报错就重做（会导致重复劳动与覆盖）。
2. **对同一文件并发发送多个 Edit 会互相覆盖**——后写入的基于旧快照，会丢改动。同一文件必须串行 Edit；批量替换改用 Python 脚本原子读写（一次 read + 内存替换 + 一次 write）。
3. Bash 的 BSD `grep` 对中文模式匹配不可靠（含 `\|` 或多字节时返回空），改用 ripgrep（Grep 工具）或 Python。
4. 检测 ASCII 图表对齐必须按**显示宽度**计算（中文 `east_asian_width in 'WF'` 记 2），否则会误报。

**审查红线（后续维护需遵守）**：
- 保留：```text 字符画、mermaid 块、标题编号、图片引用、引文/人名/书名/数据、结尾"下一节预告"、HTML 装饰块、index.md 的 YAML frontmatter
- 篇幅保持在原文 90%–108%（本次实际 92.1%）
- 感叹号仅保留在引文/对话/图表框内

**成果**：

- 说教句式"让我们/请记住/务必/一定要"清零；"不妨"残留 21 处（多为温和建议语境）
- 关键修正：18.2 删除玻姆"思想核弹"式加冕修辞、明确量子纠缠不能支撑伦理结论；17.1 删除"外在世界是分毫不差的量子共振镜"伪科学断言与目的论表述；19.1"铁律"→"著名论断"

## 第二轮：论证层面审查（13+3 处）

第一轮只处理了语气，第二轮转向**论证结构**。发现的问题更实质：

**伪科学 / 过度断言**
- `17.2` 图表内"量子微管" → "细胞骨架"（Penrose-Hameroff Orch-OR 是争议假说，主流神经科学不认可）
- `8.1` "神经营养学与脑塑性研究早已证实：创造力需要高阻力的撕裂与修复" → 区分"神经可塑性（已确立）"与"创造力需高阻力训练（经验观察，非定律）"
- `16.2` "量子场论说，大爆炸起源于真空中一次量子起伏" → 标注为"部分量子宇宙学方案中、尚未证实的理论构想"
- `16.1` 热力学第二定律加"在统计意义上"（熵增是统计性的，非绝对）

**确定性因果 / 单一归因**
- `17.1` "人生战略必然是防卫与掠夺" → "往往会倾向于" + 补例外（有人即便如此仍选择合作）
- `18.1` "深层真相往往是（童年压抑）" → "一种可能的解释是" + 补例外（也可能只是不认同张扬的表达方式）

**目的论**
- `15.2` "它逼迫植物进化出了…逼迫鸟类…逼迫哺乳动物…" → 改为自然选择下的性状筛选，并说明"四季并非有意要锻炼出什么能力"（原表述是拟人化目的论）

**最重要的一处（内容安全）**
- `6.2 躯体化投射`：**全文零处就医提示**，却通篇论证"疾病源于长期违背本性与心理压抑"，且贬低西医分科（"把人当成零件孤立的机器""吃了一抽屉药丸"）。这是典型的单一归因 + 责备受害者风险，读者若信以为真可能延误诊疗。
  修法：①缓和西医贬低为"分科在器质性疾病上成效显著，仅对功能性不适力有不逮"；②开头加"必要的前提说明"框，明确"症状先由专业医生排查""心理因素是调节变量而非唯一病因""先就医排查再辅以身心调养"；③实践建议前加就医提示；④章节小结加限定。
  **这是本轮唯一涉及现实安全风险的修改，后续若再写健康类内容必须保留此类免责。**

**顺便核实**：16.2 引用的维格纳"数学在自然科学中不可思议的有效性…我们既不理解，也不配拥有"经查证与 1960 年原论文一致（"a wonderful gift which we neither understand nor deserve"），引文准确，未改。
